# שומר הילדים – ChildGuard (מהדורה זוגית)

מערכת בטיחות חכמה למניעת שכחת ילדים ברכב, מותאמת לאייפון (Shortcuts + PWA) עם סנכרון זוגי בזמן אמת, מניעת התרעות שווא והתרעות שלא נכבות ללא בדיקה.

## יכולות עיקריות
- **סנכרון זוגי חי:** סטטוס בזמן אמת בין שני בני הזוג + חיווי מי אוסף היום מהגן + מצב נהג אורח (סבא/סבתא).
- **מנגנון אל-כשל (Pre-Beep Check):** בודק חתימת אישור ב-5 הדקות האחרונות, הורדה בגן, מצב מוסך או תדלוק לפני הפעלת צפצוף.
- **זיהוי שגרה שבורה:** התרעה מיידית אם חונים בעבודה בבוקר בלי עצירה בגן.
- **מעבדת דמו אינטראקטיבית:** 6 תרחישים לבדיקה בלחיצה אחת (גן + המשך לעבודה, שגרה שבורה, תדלוק ל-3 דק', סינון נסיעות סרק, סוללה חלשה 9%, וחניה בשרב 35°C).
- **4 שיטות אימות נגד טייס אוטומטי:** אימות מהיר ביד אחת (כפתורי ענק), לחיצה ממושכת + מתג דלת, קוד ערנות 4 ספרות אקראי, וסריקת QR במושב האחורי.

## פריסה ב-Cloudflare Pages
הפרויקט כולל הגדרות מוכנות ל-Cloudflare Pages:
- `_headers` — מאפשר הרשאות `geolocation=(self)` ו-`camera=(self)` עבור Safari באייפון.
- `functions/api/[[path]].js` — Cloudflare Pages Functions לניתובים `/api/state`, `/api/should-alarm`, `/api/event` (עם תמיכה אופציונלית ב-KV Binding בשם `CHILDGUARD_KV`).
- `wrangler.jsonc` — הגדרת הפרויקט ל-Pages.

### חיבור ל-Cloudflare Pages דרך GitHub
1. בלוח הבקרה של Cloudflare: **Workers & Pages -> Create -> Pages -> Connect to Git**.
2. בחר את המאגר **`ChildGuard`**.
3. השאר את פקודת הבנייה ריקה (`Build command: none`) ותיקיית פלט `.` (או `/` ברירת מחדל).

## הרצה מקומית במחשב
```bash
node server.js
```
ולאחר מכן פתח בדפדפן את `http://localhost:3080`.
